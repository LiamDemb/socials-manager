How to export the files
  1. Open Spotify for Artists on a computer and choose Audience. Set the range to the longest available, then Export the timeline CSV. This covers the whole artist.
  2. For a song, open Music, choose the song, set the range, then export its streams timeline CSV.
  3. Import each file here. A song file is matched to the recording you choose; its file name is only a suggestion.
